# Aurora Launcher downloads

**[Download AuroraSetup.exe — Windows 64-bit preview](https://github.com/BradersDev/aurora-downloads/releases/download/v0.1.0-preview.1/AuroraSetup.exe)**

The installer includes the complete Aurora Launcher and its Fabric 1.20.4 and
Forge 1.8.9 mod bundles. Minecraft, Java and supported official dependencies are
downloaded when requested. The installer does not include Minecraft game files,
accounts, credentials, worlds or personal settings.

## Preview status

Public Microsoft sign-in is pending maintainer registration approval/configuration.
This build is for launcher preview testing, not a general online-play rollout.
Existing users may retain their authorized Accounts configuration. A legitimate
Minecraft Java account is required for online play.

This preview is unsigned. Verify it with **SHA256SUMS.txt** on the release page;
do not disable Windows security. Install, then open Aurora Launcher from your
desktop or Start menu. Choose a game version and use Install / Repair Game.

## Privacy and source

This public repository contains download information and compiled release assets.
Aurora's development repository stays private. GitHub's automatically generated
source archives contain this download documentation, not the Aurora application
source. Compiled programs can still be inspected or reverse-engineered.

Third-party components retain their licenses. Notices are included in the installer.
Uninstall preserves personal game data. Aurora is independent and is not affiliated
with Mojang or Microsoft.
